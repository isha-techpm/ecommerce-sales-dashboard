# 📊 Ecommerce Sales Dashboard

This repository contains the **Ecommerce Sales Dashboard** built in Power BI. The report delivers clear insights into ecommerce performance, covering sales trends, customer behavior, and product-level analytics to support data-driven decision-making.

## 🚀 Key Insights
- Overall sales, revenue, and profit overview  
- Month-over-month and year-over-year sales trends  
- Best-selling and underperforming products  
- Customer segmentation and purchasing behavior  
- Category and region-wise performance  
- Order volume and operational metrics

## 🗂️ File Included
- **Ecommerce Sales Dashboard.pbix** – full Power BI report with data model, DAX measures, and visuals.

## 🛠️ Technologies Used
- Power BI Desktop  
- DAX for calculations  
- Power Query for data transformation  
- Data modeling (star schema where applicable)

## 📦 How to Use
1. Download **Ecommerce Sales Dashboard.pbix** from this repository.  
2. Open it using Power BI Desktop.  
3. Refresh or replace the data source if needed.  
4. Explore the interactive visuals and insights.

## 📈 Ideal For
- Ecommerce business owners  
- Data analysts and BI professionals  
- Product and operations teams  
- Anyone tracking online sales performance
